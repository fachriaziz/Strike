# Strike

Strike is an interactive guide to pool equipment, rules, and technique.

## Quick start

Install Node.js 22.23.4 or later with npm, then run:

```sh
git clone https://github.com/fachriaziz/Strike.git
cd Strike
npm ci
npm run dev
```

Open `http://localhost:4321`.

## Commands

- `npm run dev` starts the dev server.
- `npm run check` checks Astro and TypeScript files.
- `npm run build` creates the production build.
- `npm run start` runs the production build after building it.

Reviews are stored in `data/reviews.sqlite`.
